# ЯхтДрим — нейро-продажник яхтенной школы

Учебное полнофункциональное веб-приложение: квалифицирует потенциального клиента,
подбирает программу обучения, сохраняет заявку в базе данных и позволяет менеджеру
обрабатывать лиды в защищённой административной панели.

Приложение работает без внешних AI API и платных токенов. «Интеллектуальная» часть
реализована как прозрачная экспертная система правил, поэтому результат воспроизводим
и доступен даже без интернета.

## Возможности

- пошаговая квалификация клиента;
- персональная рекомендация программы;
- FAQ на основе публичных материалов школы;
- сохранение заявок в SQLite;
- административная панель с фильтрацией и сменой статуса;
- документация API Swagger;
- адаптивный интерфейс;
- валидация, обработка ошибок и базовые меры безопасности;
- автоматические тесты и Docker-сборка.

## Архитектура

```text
Браузер (HTML/CSS/JS)
        ↓ REST API
FastAPI → сервис рекомендаций
        ↓
SQLAlchemy → SQLite
```

## Локальный запуск

Требуется Python 3.11+.

```bash
cp .env.example .env
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements-dev.txt
uvicorn app.main:app --app-dir backend --reload
```

Открыть:

- клиентская часть: http://127.0.0.1:8000
- административная панель: http://127.0.0.1:8000/admin
- Swagger API: http://127.0.0.1:8000/docs

Для входа в админку используется значение `ADMIN_API_KEY` из локального `.env`.

## Основные API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | Проверка работоспособности |
| GET | `/api/programs` | Список программ |
| GET | `/api/faq` | Частые вопросы |
| POST | `/api/qualify` | Квалификация и сохранение лида |
| GET | `/api/admin/leads` | Список лидов, требуется ключ |
| PATCH | `/api/admin/leads/{id}` | Изменение статуса лида |

## Источник информации

Содержание учебных программ и общие сведения подготовлены по открытым материалам
[яхтенной школы Яхт Дрим](https://yachtdream.ru/). Цены, свободные места и реальные
контакты намеренно не включены. Проект не является официальным сервисом школы.
