# Безопасность

## Реализованные меры

- секреты читаются из `.env`, который исключён из Git;
- административные API требуют заголовок `X-Admin-Key`;
- ключ сравнивается безопасной функцией `hmac.compare_digest`;
- входные данные ограничены типами, длиной и форматами Pydantic;
- SQL-запросы выполняются через SQLAlchemy без ручной конкатенации;
- разрешены только необходимые CORS-методы и заголовки;
- включена проверка допустимых хостов;
- административная страница запрещена для поисковой индексации;
- Docker-контейнер запускается от непривилегированного пользователя;
- реальные токены и официальные контакты школы в проект не включены.

## Перед публикацией

1. Создать длинный случайный `ADMIN_API_KEY`.
2. Указать домен деплоя в `ALLOWED_HOSTS`.
3. Использовать HTTPS хостинга.
4. Не коммитить `.env` и базу данных.
5. Для коммерческого запуска добавить полноценную авторизацию, CSRF-защиту,
   журналирование действий и утверждённую политику обработки персональных данных.

## Учебное ограничение

Приложение является демонстрацией. Оно не заменяет CRM и не должно использоваться
для обработки реальных персональных данных без юридической и технической доработки.
